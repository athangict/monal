 Overview  
The  Stripe  Payment  Processing  API  provides  a  comprehensive  solution  for  
handling
 
online
 
payments
 
through
 
Stripe's
 
secure
 
checkout
 
system.
 
The
 
API
 
consists
 
of
 
two
 
main
 
endpoints:
 
1.  Create  Stripe  Checkout  Session  -  Initiates  payment  processing  with  
automatic
 
fee
 
calculation
 
and
 
merchant
 
validation
 2.  Check  Application  Status  -  Verifies  payment  completion  status  for  
applications
 
The  API  automatically  calculates  processing  fees,  validates  merchant  credentials,  
and
 
provides
 
secure
 
redirect
 
URLs
 
for
 
payment
 
completion.
 
All
 
transactions
 
are
 
processed
 
through
 
Stripe's
 
PCI-compliant
 
infrastructure.
 
 
Supported  Features  
●  Currency :  USD  only  (additional  currencies  coming  soon)  ●  Payment  Methods :  All  Stripe-supported  payment  methods  ●  Minimum  Transaction :  $1.00  USD  ●  Maximum  Transaction :  No  limit  (subject  to  merchant  account  limits)  
 
UAT  System  Availability  
Important  System  Access  Schedule:  
●  Weekdays  (Mon-Fri):  9:00  AM  -  5:00  PM  Bhutan  Time  (BT)  ●  Weekends  (Sat-Sun/Govt  Holidays):  System  is  NOT  available  ●  Beyond  working  hours  testing:  Requires  advance  internal  approval

Important  Notes 
Payment  Success  Criteria  
Key  Requirement  
Treat  the  payment  as  successful  ONLY  when  response_data  is  true.  All  other  responses  (including  false  or  error  responses)  should  be  considered  as  payment  not  completed.  
  
Merchant  Usage  &  Service  Policy  
Important  -  Applies  to  All  Merchants  Integrated  with  DK  Stripe  •     If  a  merchant's  transaction  causes,  or  could  potentially  cause,  harm  to  the  company's  reputation,  or  poses  a  risk  to  transactions  via  Stripe,  the  company  reserves  the  right  to  suspend  or  discontinue  services  for  that  merchant.  •     All  customer  refund  requests  must  be  directed  to  DK  Bank's  operations  team  for  processing.  •     Non-compliance  with  these  guidelines  may  result  in  temporary  suspension  of  services  until  resolved,  as  per  company  terms  and  conditions.

Transaction  Fee  Calculation  
Fee  Structure  
The  API  automatically  calculates  and  applies  the  following  fees  to  all  
transactions:
 
  


===== PAGE 18 =====

    
●  Stripe  Fee:  4.15%  of  transaction  amount  ●  DK  Fee:  0.7%  of  transaction  amount  ●  Fixed  Fee:  $0.60  per  transaction  
Fee  Calculation  Process  
The  API  performs  the  following  steps  for  fee  calculation:  
1.  Calculate  Total  Percentage  Fee:  (Amount  ×  4.85%)  ○  Stripe  Fee:  4.15%  ○  DK  Fee:  0.7%  ○  Combined:  4.85%  2.  Add  Fixed  Fee:  +  $0.60  3.  Calculate  Final  Amount:  Base  Amount  +  Total  Fees  4.  Convert  to  Cents:  Final  amount  converted  to  cents  for  Stripe  
processing
 
Rounding:  All  monetary  calculations  use  ROUND_HALF_UP  rounding  to  2  
decimal
 
places.
 
 
 
 
 
 
 
 
Fee  Examples  
$100  Transaction  Breakdown  
●  Base  Amount:  $100.00    


===== PAGE 19 =====

    
●  Fee  Calculation:  ○  Stripe  Fee:  $100.00  ×  4.15%  =  $4.15  ○  DK  Fee:  $100.00  ×  0.7%  =  $0.70  ○  Fixed  Fee:  $0.60  ○  Total  Fees:  $4.15  +  $0.70  +  $0.60  =  $5.45  ●  Final  Amount:  $100.00  +  $5.45  =  $105.45  ●  Customer  pays:  $105.45  
Customer  Display  
The  customer  will  see  the  final  amount  including  all  fees  during  the  Stripe  
checkout
 
process.
 
 
 
Notes
 
●  All  fees  are  automatically  calculated  by  the  API  ●  Fees  are  included  in  the  checkout  session  amount  ●  The  merchant  receives  the  base  amount  minus  processing  costs  ●  Duplicate  Prevention:  Idempotency  keys  prevent  duplicate  charges  for  
the
 
same
 
application
 ●  Merchant  Validation:  Both  submerchant_id  and  dk_account  are  
validated
 
against
 
the
 
merchant
 
database
 
before
 
processing
